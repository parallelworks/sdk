# Parallel Works SDKs

Official API clients for the Parallel Works ACTIVATE platform.

## Available Clients

| Language   | Package                        | Installation                               |
|------------|--------------------------------|--------------------------------------------|
| TypeScript | `@parallelworks/client`        | `npm install @parallelworks/client`        |
| Go         | `github.com/parallelworks/sdk/go` | `go get github.com/parallelworks/sdk/go` |
| Python     | `parallelworks-client`         | `pip install parallelworks-client`         |

## Version Compatibility

SDK versions match the Parallel Works platform version. For example:
- SDK v6.9.0 is compatible with platform v6.9.0

Only stable releases are published to package registries.

## Generation

These SDKs are automatically generated from the [OpenAPI specification](./openapi.json) when the core platform is released and the API specification has changed.

## Documentation

For full API documentation, visit [https://parallelworks.com/docs](https://parallelworks.com/docs).
